# Deploy SearchProxy to Vercel (5 minutes)\n\n## Step 1: Create a Vercel Account (1 minute)\n\n1. Go to https://vercel.com\n2. Click \"Sign Up\"\n3. Click \"Continue with GitHub\"\n4. Authorize Vercel to access your GitHub account\n5. Done\n\n## Step 2: Import the GitHub Repo (1 minute)\n\n1. In Vercel dashboard, click \"Add New\" → \"Project\"\n2. Click \"Import Git Repository\"\n3. Paste this URL:\n   ```\n   https://github.com/luisthemonkey123/proxy-search-website\n   ```\n4. Click \"Continue\"\n5. Click \"Import\"\n\n## Step 3: Configure (1 minute)\n\nVercel will auto-detect it's a Node.js project. Just:\n\n1. Leave all settings as default\n2. Click \"Deploy\"\n3. Wait ~2-3 minutes for the build to finish\n\n## Step 4: Open Your App (1 minute)\n\n1. When it says \"Deployment Complete\", click the URL (looks like: `https://proxy-search-website.vercel.app`)\n2. You now have a live search app\n3. Open it on your Chromebook browser\n4. Search!\n\n## That's it!\n\nYour SearchProxy is now live on the internet and accessible from any device, including your Chromebook.\n\n### To use it later:\n\nJust bookmark the Vercel URL and open it anytime.\n\n### Optional: Custom Domain\n\nIf you want a custom domain:\n\n1. In Vercel dashboard, click your project\n2. Click \"Settings\" → \"Domains\"\n3. Add your domain\n4. Follow the DNS setup instructions\n\n## Troubleshooting\n\n**Deployment failed?**\n- Check the build logs in Vercel dashboard\n- Make sure the repo is public\n\n**Search not working?**\n- Some search engines block automated requests\n- Try switching between DuckDuckGo and Bing in the app\n\n**Need help?**\n- Visit https://vercel.com/docs\n"
