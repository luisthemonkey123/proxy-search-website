Run SearchProxy on your Chromebook

You can run this app directly on your Chromebook using Linux (Beta). No downloads needed.

Option 1: Linux Terminal (Recommended)

Enable Linux on your Chromebook, then run:

git clone https://github.com/luisthemonkey123/proxy-search-website.git
cd proxy-search-website && npm install && npm start

Then open http://localhost:3000
